# 🔐 Phishing Email Detection Model

A machine learning-based phishing email detection system built using Scikit-learn. The model analyzes email text and URL features to classify emails as **Phishing** or **Safe**.

---

## 📌 Features

- Detects phishing and legitimate emails
- Uses TF-IDF for text feature extraction
- Extracts suspicious URL features
- Machine Learning classification using Logistic Regression
- Displays accuracy score and confusion matrix
- Simple and beginner-friendly implementation

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
